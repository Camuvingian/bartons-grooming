# Barton's Grooming

Marketing site and booking flow for an independent dog-grooming salon, built from `docs/plans/BARTONS_DESIGN_BRIEF.md`.

Stack: Vite, React 19, TypeScript (strict), Tailwind v4, shadcn/ui (Radix), react-router-dom v6, lucide-react, sonner.

```bash
pnpm install
pnpm dev        # http://localhost:5173
pnpm build      # typecheck + production build
pnpm lint
pnpm format
```

## Routes

| Path          | What it is                                                                     |
| ------------- | ------------------------------------------------------------------------------ |
| `/`           | Homepage: hero, ticker, services, before/after slider, price estimator, footer |
| `/book`       | Mobile-first 3-step booking flow (`?service=full&size=large` pre-fills it)     |
| `/styleguide` | Hidden gallery of the four colour schemes                                      |

## Look

A 1960s Austin Powers groove: hot colour blocks with ink outlines and hard offset shadows, mod target rings, daisies, starburst stickers and rainbow stripe bands. The logo and hero mascot are Codex's illustrated setter (two coats in `public/images/`), with a canvas soap-bubble shower that lands on the dog and a self-drawing headline underline.

- Four colour grooves (Shagadelic, Mod Squad, Flower Power, Lava Lamp), each with its own after-dark palette of deep purples, plums and teals. Every colour is a CSS variable in `src/index.css`; components only reference roles (`--brand-primary`, `--brand-sun`, `--brand-pop`, `--brand-zing`, `--brand-contrast`, `--brand-line`, …).
- Four lettering presets (Groovy = Shrikhand + Outfit, Mod = Righteous + Poppins, Bubbly = Bagel Fat One + Nunito, Classic = Bricolage Grotesque + Figtree). Each sets its own display weight and tracking via `data-font` on `<html>`, and font synthesis is off so single-weight faces are never faux-bolded.
- Setter coat: black & tan, chestnut & white, or match the theme (chestnut after dark).
- The floating cog (`SettingsMenu`) sits top-right on desktop and under the burger on mobile. Settings persist in localStorage and are applied by an inline script in `index.html` before first paint.
- Option lists live in `src/lib/theme.ts`; the provider is `src/components/theme-provider.tsx`; the hero and logo chrome is `src/styles/groovy.css`; the SVG shapes are in `src/components/groovy/`.

## Content and images

Copy is in `src/data/content.ts` (⚑ marks placeholders to confirm with the client). Before/after photos in `public/images/` are free placeholder dog photos from placedog.net; swap them for the client's. The setter illustrations were generated by Codex (see `docs/plans/SETTER_COATS.md`). Any missing or broken photo falls back to the brief's striped placeholder with a mono caption (`src/components/Photo.tsx`).
